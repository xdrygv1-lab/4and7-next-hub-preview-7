# IP 컨설팅: 벤처인증·연구소·정책자금·TCB

> **한눈에** 같은 디자인의 IP 컨설팅 안내서 세 버전(2025-08, 2026-02 두 개)을 정리했습니다. 벤처인증 요건·효과, 연구소, 정책자금 지도, R&D 자금 유형, 유상 보증, TCB까지 들어 있습니다. 금액·요건은 자료 기준일 값이라 공고 연도를 꼭 확인합니다.

**한 줄 요약:** 같은 디자인의 IP 컨설팅 소개자료 세 버전. 40번(2025-08)은 직무발명 + 벤처인증 + 정책자금 기초, 41번(2026-02-02)과 42번(2026-02-05)은 "스마트 법인 컨설팅"과 정책자금(무상·유상·R&D)을 앞세움. 42번이 41번 + 2026년 스마트 제조혁신 공고 1쪽.

**버전 차이 (한 줄씩)**
- 40번 `IP 컨설팅 안내서`(2025-08-26, 15쪽): 특허 → 직무발명(직원·대표 재설계) → 벤처인증 요건·효과 → 벤처+연구소 → 유상 정책자금 → KB 상품 예시 → TCB.
- 41번 `IP 컨설팅 안내서(정책자금 포함)`(2026-02-02, 18쪽): 앞에 "스마트 법인 컨설팅 개요"를 넣고, 벤처인증 장을 빼고, 직무발명에 "사내근로복지기금과 결합" 문구를 더하고, 정책자금(무상·R&D·스펙) 장을 추가.
- 42번 `IP컨설팅 자료`(2026-02-05, 20쪽, 제목 "IP 컨설팅 PLAN"): 41번과 같은 내용을 순서만 바꾸고(정책자금 지도 → 스마트 법인 → 직무발명 → 정책자금), 2026 스마트 제조혁신 지원사업 통합공고 표를 추가.

**핵심 내용**

① 스마트 법인 컨설팅 개요 (41번 2쪽, 42번 4쪽, "confidential")
- 개념: "개인사업자의 법인 전환 시 다양한 인증제도를 통하여 법인 전환의 효과를 극대화하는 것".
- 창업 후 3년 이내 기업: 법인전환(소득세를 법인세로) + 벤처인증("파격적인 절세효과") + 연구소 설립(실질적 인건비 감소) → "비용절감 극대화".
- 창업 후 3년 이후 기업: 법인전환 + 직무발명 보상인증 및 사내근로복지기금(절세효과 + 직원복지) + 연구소 설립 → "비용절감 극대화".
- 팀 사이트 컨셉 "스마트 법인전환"(조세특례 양수도로 감면 승계, 영업권 감정평가)과 이름이 같지만 내용 축이 다름〔이 자료는 인증 결합 중심〕.

- "파격적인 절세효과", "비용절감 극대화", "이익 극대화" → 효과 단정·과장. 사이트 원칙상 중립 표현으로.
- "보상금으로 상여금 대체 가능" → 지배주주 대표에게는 실익이 세액공제뿐(2-3-1), 직원도 정상 보상 범위 안에서만. 급여 대체로 읽히면 부인 위험.
- 정책자금 "결과 보장 불가, 보험 대가로 약속 금지"(사이트 정책자금 컨셉 원칙)와 함께 써야 함.
- 정책자금·R&D 금액은 해마다 바뀜 → 공고 연도와 기준일 표기 필수.
