# 이번에 바뀐 것: 노무 자료로 돌린 업체 분석

보내 주신 의원 두 곳 사례로 원인을 찾아 고쳤습니다. 왼쪽 [1 · 업체 분석](#go)에서 같은 자료를 다시 넣고 «돌리기»를 눌러 보세요.

## 고친 것

| 보내 주신 내용 | 원인 | 고친 것 |
|---|---|---|
| 사업자등록증·근로계약서 jpg를 못 읽음 | PDF·엑셀만 받았음 | 사진(jpg·png)도 받습니다. 사업자등록증 사진에서 상호·개업연도·개인/법인을 글자 인식으로 읽습니다 (한 장에 10~30초) |
| 사업자등록증 PDF를 넣자 돌리기가 계속 멈춤 | 스캔본 PDF는 글자 인식(1분쯤)을 하는데, 진행이 안 보여 멈춘 것처럼 보였음 | 지금 어느 파일을 읽는 중인지 화면에 보입니다. 90초가 넘으면 그 파일은 건너뛰고 계속합니다 |
| 개인 의원인데 1순위가 법인전환, 결론·스크립트가 업체와 상관없음 | 재무제표가 없어 숫자를 하나도 못 읽자, 화면에 남아 있던 **예시 회사(OO정밀, 제조·매출 12억)** 값으로 진단이 나왔음 | «돌리기»를 누르면 예시와 앞 업체 값을 먼저 모두 비우고 시작합니다. 상호에 «의원·병원·치과»가 있으면 병의원·개인사업자로 넣습니다. 의원은 법인전환이 안 되므로 관리회사(MSO)·사내근로복지기금 쪽이 먼저 나옵니다 |
| 어떤 업체를 돌려도 «○○», «○○ 공장»만 나옴 | 근로계약서 서식의 빈칸 «○○»를 회사 이름으로 읽었고, 다음 업체에서도 이름 칸이 차 있으면 바꾸지 않았음 | «○○» 같은 빈칸 표시는 회사 이름으로 쓰지 않습니다. 입력한 상호가 늘 먼저이고, 업체가 바뀌면 앞 업체의 파일·값을 비웁니다 |
| 급여대장·계정별원장·복지 현황을 넣어도 반영이 안 됨 | 재무제표만 읽었음 | 급여대장에서 **직원 수·월 급여 합계**, 계정별원장에서 **복리후생비·접대비 누계**를 읽습니다. 복지 현황 같은 글 파일은 «업체 이야기»에 들어가 컨셉·스크립트·롤플레이가 같이 씁니다 |

재무제표가 없을 때는 «재무제표·종합소득세 신고서가 없어 매출·이익·회사 가치 숫자는 비어 있어요»라고 알려 줍니다. 업종을 못 읽으면 «더 맞게 고르기»에 새로 넣은 **업종** 칸에서 고르면 됩니다.

## 가상 의원으로 돌려 본 결과

지어낸 의원 자료(급여대장 3개월, 근로계약서, 계정별원장, 복지 현황, 사업자등록증 사진·스캔본)로 돌렸습니다.

- 상호·업종·형태: 입력한 의원 이름 · 병의원 · 개인사업자
- 직원 8명, 월 급여 합계 약 2,550만원, 복리후생비 연 약 1,480만원을 읽음
- 컨셉: 1. 병의원 관리회사(MSO) 2. 인건비 구조(사내근로복지기금) 3. 노후자금
- 예시 회사·공장 멘트 없음. 다른 업체를 이어서 돌려도 앞 업체 값이 남지 않음

## 롤플레이 («사근복 얘기에 보험 얘기 아니냐»)

말씀하신 대로 실제로 나올 수 있는 흐름이라 그대로 두었습니다. 대신 이제 AI 대표가 넣은 자료(직원 수·복지 현황 등)를 알고 나옵니다. [2 · AP 단계](#ap)에서 업체를 불러와 롤플레이를 열어 보세요.

## 확인 부탁드릴 것

- 보내 주신 두 의원 자료를 같은 방식으로 다시 넣어 보시고, 컨셉 1~3순위와 스크립트가 맞는지
- 급여대장은 «성명(사원명)»과 «지급합계» 칸을 기준으로 읽습니다. 서식이 달라 직원 수가 안 읽히면 어떤 서식인지 알려 주세요
- 의원 노무 컨셉 순서(관리회사 → 사내근로복지기금 → 노후자금)가 맞는지
