# 컨셉별 AP 카드: 법인전환

> **한눈에** 이익이 나기 시작한 **개인사업자**를 만나는 AP에서 쓰는 카드입니다. AP의 목표는 법인전환을 제안하는 것이 아니라, 대표가 **"지금 구조로는 손해다"를 자기 입으로 말하게** 하고 PC 약속을 잡는 것입니다. A형(법인전환을 PC에서 제안할 생각으로 들어갈 때)과 B형 · 가결산 미팅에서 니즈를 파악할 때 둘 다 쓸 수 있습니다.

⚠ 초안입니다. ★ 후킹 포인트 칸은 실제 경험으로 채워야 완성됩니다. 세무 처리는 세무사 검토 사항입니다.

## 1. 이 카드를 쓰는 회사

| 신호 | 강도 | 어디서 확인 |
|---|---|---|
| 순이익 **1억** 초과 (35% 구간 이상) | ●●● | 장부 |
| "법인이 유리하냐" 물어본 적 있음 | ●●● | 기억, 상담 기록 |
| 입찰·대출 때문에 법인 문의 | ●●● | 기억 |
| 성실신고확인 대상 또는 직전 (도소매 등 **15억** / 제조·음식숙박·건설 등 **7.5억** / 서비스·부동산임대 등 **5억**) | ●● | 장부 |
| 창업감면 종료 임박 | ●● | 장부 |
| 매출 급증, 추가 점포·확장 계획 | ●● | 장부, 대화 |
| 공장·설비·건물이 대표 개인 명의 | ● | 장부 |
| 자녀 증여 이력 | ● | 신고 이력 |
| **결손 누적, 현금흐름 빠듯** | 반대 신호 | 장부 |

- **법인 대표**라면 이 카드가 아닙니다. → 대표 퇴직금 재원, 상속세 재원, 가업승계 카드로
- 개인사업자인데 **부동산이 크면** → 부동산 현물출자 법인전환 카드를 함께 봅니다

## 2. A형: 니즈 환기형 (PC에서 법인전환을 제안할 생각으로 들어갈 때)

미션: 대표 입에서 **"세금이 너무 많다 / 손에 남는 게 없다 / 퇴직금이 없다"** 가 나오게 하기

| 단계 | 이렇게 말하기 | 체크 |
|---|---|---|
| 04 방문목적 | "결산도 결산이지만, 올해 숫자를 보니 대표님께 꼭 한번 여쭤보고 싶은 게 생겼습니다." | 궁금증만, 결론 금지 |
| 06 일반 사례 | "종합소득세 최고세율이 지방세까지 **49.5%**입니다. 건강보험료까지 더하면 많이 버는 구간에서는 거의 절반을 국가가 가져갑니다." | 객관 팩트만 |
| 07 우리 회사 숫자 | "올해 당기순이익이 [ ]억이라 [ ]% 구간에 들어오셨습니다. 매출도 [ ]억이라 성실신고 [대상이세요 / 바로 앞이세요]." | 장부 숫자 그대로 |
| 08 니즈환기 질문 | ① "제가 숫자는 알고 있는데, 대표님은 올해 세금이랑 건보료로 **체감상 얼마나 나갔다고** 느끼세요?" <br>② "버신 것 중에 실제로 **손에 남는 건** 어느 정도라고 느끼세요?" <br>③ "내년에는 매출이 더 늘 것 같으세요? 계획하고 계신 게 있으세요?" <br>④ "이 사업은 언제까지 하실 생각이세요? 그때 **퇴직금 같은 목돈**은 어디서 나올까요?" <br>⑤ "월 생활비는 어느 정도 쓰세요?" | 숫자는 대표 입에서 |
| 09 문제제기 | "매년 세금과 건보료로 [대표가 말한 금액]이 나가고, [은퇴까지 남은 해]년이면 [곱한 값]입니다. 그런데 은퇴하실 때 받는 퇴직금은 **0원**입니다." | 감정 없이 산수만 |
| 10 선거절 | "법인 하면 귀찮고, 돈을 마음대로 못 쓴다는 얘기 들어보셨죠. 맞습니다. 그래서 이익이 1억 안 되는 분들께는 권하지 않습니다. 대표님은 이제 **그 구간을 지나셨습니다.**" | 단점 먼저 인정 → 자격으로 반전 |
| 11 대안 | "이제 법인이라는 **그릇**으로 옮기실 때가 된 것 같습니다. 그릇이 바뀌면 세율, 대표님 퇴직금, 가족과 나누는 구조 세 가지가 달라집니다. 숫자는 다음에 보여드리겠습니다." | 방법·절차 설명 금지 |
| 15 다음 약속 | "법인으로 옮겼을 때 1년에 손에 남는 돈이 얼마나 달라지는지, 퇴직금은 얼마까지 만들 수 있는지 시뮬레이션을 가져오겠습니다. [요일] [시각], 한 시간 잡아주세요." | 일자+시각+소요시간+가져올 것 |
| ☆ 소개요청 | "주변에 대표님처럼 **이익이 나기 시작한** 개인사업자 분 딱 두 분만 소개해 주세요. 이 갈림길은 이익이 나기 시작한 분들만 서게 됩니다." | 10단계 "구간" 논리 회수 |

## 3. B형: 니즈 파악형 · 가결산 미팅에서 무엇이 필요한지 모를 때

결산 숫자를 설명하면서 아래 질문을 자연스럽게 섞습니다. **답에 따라 법인전환 후보 점수가 올라가거나 내려갑니다.**

| 탐색 질문 | 이런 답이면 | 법인전환 |
|---|---|---|
| "올해 세금 보시니까 어떠세요?" | "너무 많이 낸다", "번 거 다 세금이다" | ▲▲ |
| "건보료는 부담 안 되세요?" | "건보료가 더 아깝다" | ▲ |
| "내년엔 어떻게 될 것 같으세요?" | 매출 증가, 지점 추가, 직원 충원 | ▲ |
| "혹시 입찰이나 대출 때문에 불편한 점 없으세요?" | "법인이 아니라서 안 된다는 데가 있다" | ▲▲ |
| "이 사업은 언제까지 하실 생각이세요?" | "퇴직금도 없는데 걱정이다" | ▲ (노후자금 카드와 함께) |
| "자녀분이 이 일을 이어받을 수도 있을까요?" | "생각 있다", "가르치고 있다" | ▲ (가족법인 구조로) |
| "돈이 들어오면 바로바로 쓰셔야 하는 편이세요?" | "사업 돈이 곧 생활비다" | ▼ (돈 분리가 어려움) |
| "요즘 자금 사정은 어떠세요?" | "빠듯하다", "몇 년 안에 접을 생각" | ▼▼ |

- ▲가 **3개 이상**이면 PC 컨셉을 법인전환으로 정하고, AP 후 기록지에 근거가 된 대표의 말을 그대로 적습니다.
- B형에서는 09·11단계를 그 자리에서 고릅니다. 세금 반응이 크면 2장의 09·11 멘트를 쓰고, 그렇지 않으면 "말씀하신 걸 정리해서 맞는 방향을 가져오겠습니다"로 마무리합니다.

## 4. 꼭 받을 F.F

기장거래처라 장부로 이미 아는 것(●)이 많습니다. AP 전에 체크하고 **○·◐만 묻습니다.**

| 항목 | 왜 필요한가 (PC 준비) | 보통 상태 | 묻는 말 |
|---|---|---|---|
| 순이익·매출·세금·건보료 | 개인 유지 vs 법인 비교 | ● 장부 | (묻지 않음, 07단계 재료) |
| 감면·이월공제 | 전환 방식 선택 | ● 장부 | (묻지 않음) |
| 사업장 자가/임차, 명의 | 전환 방식, 상속재산 | ◐ | "공장은 지금도 대표님 명의 그대로죠?" |
| 사업장 외 부동산·금융자산 | 현물출자 여부, 전체 자산 | ○ | "사업장 말고 따로 갖고 계신 게 있으세요?" |
| 개인 명의 대출 | 대출 정리 동선 | ◐ | "대출은 지금 어디서 얼마 정도 있으세요?" |
| 배우자·자녀 나이, 하는 일 | 가족 지분 설계 | ◐ | "자녀분은 지금 어떤 일을 하세요?" |
| 자녀 승계 의향 | 가족법인 구조 | ○ | "나중에 이 일을 자녀분이 이어받으면 어떨 것 같으세요?" |
| 은퇴 시점·월 생활비 | 퇴직금 목표액 | ○ | 08단계 ④⑤ |
| 돈 분리 감내 의향 | 전환 가능 여부 | ○ | "법인 돈과 개인 돈을 나눠 쓰는 불편함, 감수하실 수 있으세요?" |
| 기존 보험 (가입 스토리) | PC 퇴직금 재원 설계 | ◐ | "보험은 어떻게 가입하셨어요?" |

## 5. AP에서 절대 말하지 않을 것

| 말하지 말 것 | 이유 |
|---|---|
| 현물출자, 포괄양수도, 영업권, 감면 승계 | 절차 설명은 PC 이후. AP에서 꺼내면 "복잡하다"로 끝남 |
| 법인세율 숫자, 절세 금액 | PC 내용 미리 말하기 **−5** |
| 경영인정기보험, 종신보험 등 상품명 | **−5** |
| "세금을 줄여드립니다" | 확정 표현 |
| "법인전환 컨셉을 가져왔습니다" | 컨셉명은 내부용 |

## 6. PC로 넘길 메모 (고객에게 말하지 않음)

- 개인 유지 vs 법인 전환 손에 남는 돈 비교 (허브 예시: 순이익 2억 → 가용현금 **1억 600만원 vs 1억 7,330만원**, 단순화 가정)
- 전환 방식: 부동산 유무, 감면 잔존, 대출에 따라 조세특례 양수도 / 일반 양수도 / 현물출자 중 선택
- 대표 급여·퇴직금 규정 설계 → 퇴직금 재원은 경영인정기 또는 원금형 종신 (신설법인 가입 제한 확인 필요)
- 가족 지분 구조 (자녀 나이·소득, 증여 합산기간 확인 필요)
