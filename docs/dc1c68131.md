## 자료 학습

### 9. 폴더 자료: 변리사 제안서 (2025-12-20, 5쪽, 작성 변리사 발신, 고객사명 생략)

실제 고객 제안서. 숫자와 세무 내용은 작성 시점 기준이며 세무 처리는 세무사 검토 사항.

### 구조

특허 출원 → 직무발명 규정·보상 절차 → 보상금 지급 → 벤처인증 → 금융상품 결합. 자료의 표현은 "기술 권리화 + 절세 + 기업 공신력 상승".
결합의 논리: 보상금으로 줄어든 법인세를 보험료 재원으로 돌려 "잉여금 해소 + 리스크 헷지 + 법인세 절감". 3단 그림으로 설명(제도 없음 → 보상금 효과 → 보상금 + 금융상품).

### 자료의 주장 (세무사 확인 전 단정 금지)

- 종업원: 1인당 연 700만원 한도 비과세, 4대보험·퇴직금 적립액 감소 효과, 보상금의 25% 연구세액공제(2억 지급 시 5,000만원).
- 대표·특수관계 임원: 비과세는 안 되지만 25% 세액공제 대상. 사이트는 이 부분을 "확인 필요"로 둠.
- 절차와 특허 출원 없이 지급하면 인정되지 않음. 유통 방식 자동화 같은 아이디어도 직무발명 사례로 제시.

### 10-1. 영업 자료 (안내서 PPT, 견적서)

- 안내서 흐름: 특허권의 효력(독점·배타 + 정책자금·R&D·절세 등 파생 효력) → 직무발명 개념(발명진흥법 §2) → 효과(연구·인력개발비 세액공제 25%, 종업원 연 700만원 비과세, 직무발명 우수기업 인증과 정책자금 연계) → 2024 개정으로 지배주주·친족은 비과세 제외 → 대표 급여 재설계 비교 → 지급 절차("사후관리의 시작") → 금융상품 결합 그림.
- 대표 2억 비교〔자료 예시〕: 상여는 회사 부담 약 7,666만(세금 6,000 + 퇴직금 1,666), 직무발명 보상금은 약 1,000만(세금 6,000 − 세액공제 5,000, 퇴직금 0). 사이트 컨셉 사전의 "7,666만 vs 1,000만"과 같은 숫자로, 이 PPT가 출처로 보임.
- 대표·특수관계 임원 보상금의 25% 세액공제 근거로 대법원 2013두2655를 제시. 사이트는 이 부분을 "확인 필요"로 둠(9번 항목과 같은 쟁점). 세무사 확인 전 단정 금지.
- 견적서 3종의 금융상품 월 납입액이 서로 다름: 2025-12 PDF 4,000만원, 2025-12-20 제안서 1,000만원, 2026-03 Word(다른 수신처) 500만원(특허 10건 출원 예정). 고객별 설계 예시이며 상품명·기준일 표기는 없음.

### 10-2. 실행 단계 자료 (실행철, 2026-11-02)

실행가이드 결론〔자료 표현 요약〕:
- 금액: 실시보상금은 실시료법 산식(매출 × 독점권기여도 × 실시료율 × 발명의 기여도 × 발명자 공헌도)으로 방어 가능한 범위가 연 약 1.0억(적용안)~1.33억(상한). "연 5억을 단일 연도에 맞추려는 설계는 산식과 충돌하므로 하지 않는다."
- 세금: 지배주주 대표는 비과세 700만원 적용 불가 → 상여와 같이 근로소득 과세. 상여 대비 실익은 세액공제(연 1억 기준 약 2,500만)뿐이고, 이 실익을 지키는 비용이 "절차".
- 리스크: 가장 비슷한 선례(조심 2024부208: 형식적 규정, 대표에게만 지급, 직원 발명 제외, 절차 미비, 서류 소급 → 손금·공제 부인)의 요소를 서류로 하나씩 해소.
- 검토에서 발견한 문제: 종업원 협의 없이 제정된 규정, 같은 날짜로 작성된 신고서(소급 정황), 분쟁용 서식(심의요구서)을 보상 요청에 사용, 심의위원회 미구성, 발명자가 대표 100%(직원 기여 미확인).
- 산정 파라미터 3안: A 보수(독점 33%·실시료 3%·공헌 10%, 매출 대비 0.10%) / B 적용안(50%·5%·30%, 0.75%) / C 상한(50%·5%·40%, 1.00%). 승계일 이후 매출만, 제품–특허 대응표, 매년 재산정, C 초과 금지.
- 정액 출원·등록보상(건당 2,000만·4,000만원)은 대표 지시로 유지하되, 세무사는 부인 위험이 크다고 자문 → 완충책 4가지: 직원에게도 같은 금액 실제 지급, 실시보상에서 기지급액 상계(불리한 변경이라 과반수 동의 필요), 지급 시점 분산, 금액 결정 사유 기록.
- 주주총회 연간 한도 결의(예시 4억 8,000만원), 회의록 10년 보존 권장, 세무조사 대응 파일 목차 상시 비치.
- 쟁점별 방어 서류 매핑: 규정 형식 도입 / 위원회 미구성 / 대표에게만 지급 / 서류 소급 / 정상가액 초과(대법 2020두34476) / 개인특허 양수 우회(조심 2023인10103) / 발명자성 부정(적부 2019-0101) / R&D 실체 / 임원 보수 한도 / 비과세 오적용.

- 발명진흥법상 서면통지 3종: 규정 제정·변경 통지, 승계 여부 통지(4개월 내), 보상액 결정 통지.

### 10-3. 규정 제정안과 산정 보고서 (2026-11-05)

- 규정 제정안: 특허청 표준모델(민간 30인 이상, 2024-08-07) 기반, 외부 세무법인의 수정 요청 반영. 주요 변경: 보상금은 심의위원회 결정일에 확정·60일 내 지급(손금 귀속 시기), 실시·처분보상 매년 재산정, 임원 보상은 정관·주총 한도 내 지급 후 보고, 퇴직자 보상 표준 복원, 기승계 발명 목록과 경과조치.
- [별표 2] 출원·등록보상 등급제(100점 평가, 사업기여도 35점은 매출 구간표로 산정): S 1,000만/2,000만 · A 600만/1,200만 · B 300만/600만 · C 100만/300만 · 기준 미달 50만/100만. "미지급" 등급 없음, 실용신안·디자인 50%.
- [별표 3] 실시보상 슬라이드법(특허청 편람): 기준금액 = 실시 제품 순이익 × 이용률. 1,000만 이하 30% / 5,000만 이하 20% + 100만 / 초과 15% + 350만. 실시료법 산출액을 참고로 병기하고 "높은 쪽 선택" 조항은 두지 않음.
- 부속 서식집(A~J): 2026-01-02 초안과 그 서류는 폐기하지 않고 "미채택 서류철"로 보관, 모든 서식은 실제 일자로 작성(소급 금지).
- 산정 보고서(10쪽): 2026년 1~10월 특허품목 납품액을 12개월로 연환산(약 73억, 총매출의 56.4%), 전사 이익률 23.08%로 순이익 안분.
 - 슬라이드법 1.30억~4.54억, 실시료법(법원 기본 산식) 연 1,650만~4,400만.
 - 채택안: 회사 순이익 30억 전액 × 15% + 350만 = 4억 5,350만원, 출원·등록보상(건당 500만·430만) 합산 총 5억. 보고서 스스로 "5억에 맞춘 예시"라고 적음.
 - 보고서가 밝힌 위험: 실시료법 결과가 과세관청이 주장할 수 있는 "시가의 바닥"이며 채택안은 그 10~27배. 정당화 논리로 대체·보완 매출(대법 2014다220347), 출원 청구범위, 규정 별표 명문화, 복수 특허·연도를 제시.
 - 권고: 1차로 특허품목 통합 기준 약 2.57억 지급, 정당화 자료와 심의위원회 의결 후 차액 추가 지급하는 2단계 구조가 가장 방어적.

### 11. 폴더 자료: 벤처투자조합·IP 컨설팅·정책자금 (2026-11-22 학습, 고객명 생략)

- 출처: 벤처투자조합 컨설팅 안내 PPT〔2026-10, 2차 미팅용, 고객사명 생략〕, IP 컨설팅 안내서 PDF 3종(2025-08, 2026-02-02, 2026-02-05). 모두 작성 변리사 작성.
- 세무 숫자는 자료 작성 시점 기준이며 세무사 검토 사항.

### 11-1. 벤처투자조합 + 직무발명 (PPT 19장)

- 구조: 대표 개인은 벤처투자조합 출자로 소득공제("개인 절세 영역"), 법인은 직무발명 보상·연구전담부서로 세액공제("법인 절세 영역"). 그림 속 표기: "벤투조합 → 법인(역할부여)", "회수조건부", "벤처인증", "활용: (ex) 자산구매".
- 소득공제율〔자료 표기〕: 투자액 3천만원 이하 100% / 3천만~5천만원 70% / 5천만원 초과 30%. 공제 한도·보유기간·특수관계 기업 제외 같은 요건은 자료에 없음 → 세무사 확인.
- 국세청 회신 인용: 개인투자조합이 벤처기업의 3년 만기 무담보 전환사채를 인수해도 조특법 §16①3호 공제 가능, 조합이 만기 후 회수하는 것은 §16②3호(추징 사유)가 아님. 회신 번호·날짜는 자료에 없음.
- "자산 구매 목적이면 사업용 자산만 가능"(근거 조문 미기재).
- 상표권 양도 비교: 가치 1억 → 필요경비 60% 공제 후 기타소득세 약 800만원, 자산 평가 없이 종합소득으로 내면 약 2,010만원(가정 미기재). 대안으로 직무발명 보상 1억 → 25% 세액공제 2,500만원, "'권리'가 아닌 '아이디어'를 이전".
- 직무발명 퀴즈 8문항: 근무 중·퇴사 후 같은 분야 발명은 직무발명, 다른 분야는 아님, 공무원·대표자 발명도 직무발명, "대표자는 효과를 누릴 수 없다"는 X(△).
- 사이트 원칙과 충돌 소지: 사이트 "벤처투자조합 소득공제" 컨셉은 "본인 법인 투자는 조사 위험". 자료 구조가 대표 본인 법인 투자로 읽히면 공제 배제·조사 위험. "회수조건부", "실질적 급여 조절 가능" 표현 주의.

### 11-2. 벤처인증·연구소 (IP 컨설팅 안내서, 2025-08)

- 요건 4유형: 벤처투자(적격투자기관 5천만원 이상 + 자본금 대비 10% 이상), 연구개발〔연구소·전담부서 + 직전 4분기 연구비 5천만원 이상 + 매출 대비 5% 이상〕, 혁신성장(기술 혁신성 + 성장성), 예비벤처(설립·등록 준비 중).
- 효과〔자료 표기〕: 법인세·소득세 최대 5년 50% 감면(창업 3년 내 인증, 조특법 §6②), 취득세 75% 감면, 재산세 3년 면제 + 2년 50%(지특법 §58의3②), 기보 보증한도 30억 → 50억, 코스닥 심사 우대(자기자본 30억 → 15억 등), 촉진지구 취득세 50%·재산세 35%, 대기업 인수 시 계열편입 7년 유예, 스톡옵션 대상·한도 확대, 방송 광고비 최대 70% 할인. 2025-08 기준이며 개정 여부 확인 필요.
- 연구소·전담부서: 기보 요건 완성, 배치 인력 인건비 25% 세액공제, R&D 무상지원 요건, 사후관리 중요.

### 11-3. 정책자금·TCB (IP 컨설팅 안내서, 2026-02)

- "스마트 법인 컨설팅": 창업 3년 이내 = 법인전환 + 벤처인증 + 연구소 / 3년 이후 = 법인전환 + 직무발명 보상인증·사내근로복지기금 + 연구소. 사이트 컨셉 "스마트 법인전환"(조세특례 양수도)과 이름만 같고 내용이 다름.
- 정책자금 지도: 무상(사업화·R&D·바우처) / 유상(기보·신보·신용보증재단·중진공, 시중은행 IP 담보대출) / 절세 포인트〔벤처·메인비즈·이노비즈 인증, 직무발명·연구소 R&D 세액공제〕.
- R&D 유형〔자료 표기〕: 창업성장 기술개발(매출 20억 이하, 7년 이하) 디딤돌 최대 1년 1.2억(다른 쪽은 2억), 전략형 3억, TIPS 최대 2년 5억·3년 15억 / 기술혁신개발(매출 20억 이상) 수출지향형 4년 20억, 시장확대형 2년 6억, 시장대응형 2년 5억.
- 정책자금 집행 스펙: 인력〔연구소 인건비 25% 절세, 보상금으로 상여 대체〕 / 매출(지원금·마케팅) / 특허(포트폴리오 3개, 등록 6~9개월) / 인증(창업 3년 내 빠른 구축).
- 유상 보증 종류(일반·IP 담보·IP 우대): 기보 1·3·1, 신보 1·2·1, 신용보증재단 1·2, 중진공 1·1. KB IP 대출 상품 3종 캡처.
- TCB: 가점 항목〔특허 등록 7개 만점, 연구소 만점, 벤처·이노비즈·메인비즈·ISO, 연구원 수·경력〕, 평가기관 5곳, 용도별 비용(입찰용 30~40만, 공공 R&D용 70~80만, 은행용 은행 부담), 조달우수제품은 BBB 이상 또는 TCB-4 이상, 등급은 단기간에 바꾸기 어려움.
- 직원 2억 비교표: 상여는 퇴직금 1,666만 + 4대보험 2,200만 = 3,866만 추가 비용, 보상금은 세액공제 5,000만(퇴직금·4대보험 0 전제). 4대보험·퇴직금 제외 전제는 세무사·노무사 확인 필요.
- 2026년 스마트 제조혁신 지원사업 통합공고(중기부 공고 제2025-574호, 2025-10-31) 표 첨부(이미지).
