# AP 스크립트 개선 기획: 미션 A·B, F.F 체크판, 사례 은행

> **한눈에** 지금 AP 스크립트는 "틀"은 좋지만, 어느 회사를 넣어도 비슷한 말이 나옵니다. 개선 방향은 세 가지입니다. **컨셉마다 다른 말**, **내 경험이 들어간 말**, **현장에서 검증된 말**. 여기에 두 가지 설계를 더합니다. **오늘 AP의 미션(니즈 환기형 / 니즈 파악형) 고르기**, **이미 아는 것은 빼고 모르는 F.F만 놓치지 않고 묻기**. 결과물은 모두 MD 문서로 만들어 허브 담당에게 넘기면 사이트에 바로 반영됩니다.

## 1. 지금 상태 진단

허브의 `업체 분석 → 제안 준비` 도구가 AP 스크립트를 만드는 방식을 직접 열어 보았습니다.

| 구분 | 지금 | 문제 |
|---|---|---|
| 15단계 구조 | 표준·시간·채점표·금지어까지 완성 | 문제 없음. 이 틀은 그대로 유지 |
| 06~07 (사례로 니즈 열기) | 도구 속 컨셉 19개 중 **3개**(사근복·세무리스크·가족법인)만 전용 멘트. 나머지는 개인/법인/자산가 3갈래 공통 멘트 | 가지급금이든 직무발명이든 같은 첫 마디가 나옴 |
| 08 (니즈환기 질문) | 공통 질문 5개(은퇴 생활비) + 컨셉별 질문 1개 | 대부분 은퇴 이야기로 흘러감 |
| 11 (대안제시) | 컨셉별 한 줄 | 무난하지만 "후킹"이 약함 |
| 03·13 (내 사례) | 모든 사람에게 같은 예시 사례 2개 | "본인 경험으로 바꾸세요"라고만 하고, 바꿀 재료가 없음 |
| 자격사별 차이 | 02단계 한 문장만 다름 | 10/14에 정한 "AP부터 세무사/노무사/변리사별로" 미반영 |
| 저항 대응 | 7가지 | "거절처리 20장" 문서는 빈 상태 |
| 업체 분석 활용 | 신호등 8가지·기사 정보가 01단계와 질문 일부에만 쓰임 | 분석은 깊은데 스크립트로 잘 안 이어짐 |
| 검증 | 채점표는 있지만 실제 미팅 결과를 모으는 길이 없음 | 어떤 말이 계약으로 이어졌는지 알 수 없음 |

## 2. 개선 방향 3가지

| 방향 | 한 줄 | 왜 중요한가 |
|---|---|---|
| ① 컨셉마다 다른 말 | "컨셉별 AP 카드"를 만든다 | 팀이 정한 우리만의 차별점("컨셉 사전 촘촘하게")이 바로 이것 |
| ② 내 경험이 들어간 말 | 지점원마다 "나의 사례 은행"을 갖게 한다 | 남이 흉내 낼 수 없는 스크립트 (킥오프 때 나온 "모방 불가" 방향) |
| ③ 현장에서 검증된 말 | 미팅 후 결과를 모아 멘트를 고친다 | "빨리 시작해서 사례를 먼저 쌓는 쪽이 이긴다" |

## 3. 실행 계획

### 1단계: 컨셉별 AP 카드 (가장 먼저, 효과 가장 큼)

컨셉 하나당 카드 한 장. AP 15단계 중 **컨셉에 따라 달라지는 칸만** 채웁니다.

| 칸 | 내용 |
|---|---|
| 이런 회사에 | 재무·상황 신호 (예: 가지급금 계정 있음, 대표 60세 이상) |
| 06 일반 사례 | 반박 못 하는 객관 팩트 한 문장 |
| 07 우리 회사 숫자 | 재무제표 어느 숫자를 꺼내 말할지 |
| 08 니즈 질문 3개 | 상대 입에서 숫자가 나오게 하는 질문 |
| 09 문제제기 | 필요액 vs 준비액을 어떻게 나란히 놓을지 |
| 10 선거절 | 이 컨셉에서 꼭 나오는 저항과 먼저 꺼내는 말 |
| 11 대안 한 마디 | 상품명 없이 기대감만 남기는 말 |
| 15 가져올 것 | 다음 약속 때 무엇을 가져간다고 할지 |
| 꼭 받을 FF | 이 컨셉 PC를 준비하려면 반드시 알아야 할 정보 (5번 설계와 연결) |
| B형 탐색 질문 | 니즈 파악형 AP에서 이 컨셉 후보를 가려내는 질문 + "이 답이면 이 컨셉" |
| ★ 후킹 포인트 | **실제로 대표님 마음이 움직였던 한마디** (팀원 노하우로 채움) |

- 순서: 상담 빈도가 높은 것부터 **5개 → 10개 → 19개 전체**
 - 1차 후보: 법인전환, 상속세 재원(법인 대표), 가지급금 해소, 대표 퇴직금 재원, 가업승계
- ★ 후킹 포인트 칸은 담당 팀원에게 받습니다 (예: 사근복은 노무사 담당, 직무발명·밸류업은 변리사 담당, 승계·상속은 회계사 담당).
- 산출물: `컨셉별AP카드_법인전환.md` 같은 컨셉별 파일

### 2단계: 자격사별 AP 흐름

같은 기업분석에서 출발하되, 03단계(왜 왔는지)·06단계(첫 화제)·11단계(대안)가 자격사마다 다릅니다.

| 자격사 | 자연스러운 진입 명분 | 주력 컨셉 |
|---|---|---|
| 세무사 | 결산·가결산, 세무조사 대비 | 법인전환, 상속, 가지급금 |
| 노무사 | 노무 점검, 인건비 구조 | 사근복, 고용지원금 |
| 변리사 | 기술·특허 점검 | 직무발명, 밸류업, 벤처인증 |
| 회계사 | 외부감사, 기업가치 평가 | 승계, 비상장주식 평가 |

- 세무사 흐름은 제가 직접 쓰고, 노무사·변리사 흐름은 노무사·변리사 담당과 함께 만듭니다.

### 3단계: 나의 사례 은행

03·13단계에 넣을 **내 실제 경험**을 미리 적어 두는 칸입니다.

| 항목 | 예 |
|---|---|
| 포지션을 바꾼 계기 | 실제 있었던 일 (고객 이름 빼고) |
| 대비 못 해서 힘들었던 거래처 | 13단계에서 회수할 이야기 |
| 대비해서 버틴 거래처 | 13단계 반대편 이야기 |
| 나의 말투 | 자주 쓰는 표현, 피하고 싶은 표현 |

- 먼저 제 사례로 견본을 만들고, 사이트에 입력 칸을 붙여 달라고 허브 담당에게 요청합니다.

### 4단계: 비어 있는 문서 채우기

| 문서 | 내용 |
|---|---|
| 거절처리 20장 | 단계별(TA·AP·PC·C)로 자주 나오는 거절 20개와 실전 멘트, 5가지 패턴 |
| 질문집 | 첫 미팅 질문, 30·40·50·60대 대표별 질문 |
| RP 피드백 양식 | 채점표를 연습용 한 장으로 + 자주 나오는 지적 8가지 |

### 5단계: 현장 검증 순환

1. AP 전: 도구로 스크립트 만들기
2. AP 후: 녹음이나 메모로 "실제로 한 말, 상대 반응, 다음 약속 여부" 남기기
3. 채점표로 점수 매기기
4. 효과 있던 말 → AP 카드 ★칸에 추가, 안 통한 말 → 금지어나 주의로

목표: 2개월 안에 실제 AP **10건**을 이 순서로 돌려 보고 결과를 사업단에 보여 주기

## 4. 설계 추가 ①: 오늘 AP의 미션 고르기 (A형 / B형)

AP는 제안하는 자리가 아니라 **PC로 넘어가기 위한 단계**입니다. 그런데 AP의 미션은 상황에 따라 두 가지로 나뉩니다.

| 미션 | 언제 | AP에서 할 일 |
|---|---|---|
| **A. 니즈 환기형** | PC에서 제안할 컨셉을 정해 두고 들어갈 때 (예: 법인전환) | 그 컨셉의 니즈를 대표 입으로 인정하게 만들기 |
| **B. 니즈 파악형** | 가결산·결산 미팅을 AP로 활용할 때, 아직 무엇이 필요한지 모를 때 | 대표의 생각과 니즈를 파악해서 PC 방향 정하기 |

### 입력 화면

```
④ 오늘 AP의 미션
 ○ A. 니즈 환기형: PC에서 제안할 컨셉이 정해져 있음
 → [PC 컨셉 선택 ▼] (자동 진단 1순위가 미리 선택, 변경 가능)
 ○ B. 니즈 파악형: 가결산·결산 미팅을 AP로 활용, 아직 모름
 → 자동 진단 후보 컨셉 2~3개를 "가설"로 표시 (체크로 빼고 넣기)
```

- "미팅 성격 = 가결산 겸"이고 컨셉을 고르지 않으면 **B가 기본**, 컨셉을 고르면 A로 바뀜
- 사업 형태(개인/법인)와 곱해져 **4가지 스크립트**가 나옴

### 미션별로 달라지는 단계

공통 틀(01~05 진입, 12~13 예화, 15 약속, 소개요청)은 그대로 두고, 아래 단계만 달라집니다.

| 단계 | A. 니즈 환기형 | B. 니즈 파악형 |
|---|---|---|
| 04 방문목적 | "대표님 회사 숫자로 보이는 게 하나 있어서요" | "결산도 결산이지만, 대표님 이야기를 좀 들어보려고요" |
| 06~07 사례 | 그 컨셉 하나로 좁혀서 (개인: 세율·건보료 / 법인: 주식가치) | 결산 숫자에서 보이는 **신호 2~3개를 가볍게** |
| 08 질문 | 그 컨셉 니즈를 **대표 입으로 인정**하게 하는 질문 | **탐색 질문 묶음**, 질문마다 "이 답이면 → 컨셉 후보" 표시 |
| 09 문제제기 | 필요액 vs 준비액을 그 컨셉 기준으로 | 대표가 가장 크게 반응한 주제로 현장에서 고름 (멘트 2~3개 준비) |
| 11 대안 | "법인이라는 그릇으로 옮기실 때입니다" | "말씀하신 걸 정리해서 맞는 방향을 가져오겠습니다" |
| 14 F.F | 그 컨셉 PC 시뮬레이션에 필요한 자료 | 후보 컨셉을 가려낼 수 있는 정보 |
| 15 가져올 것 | "법인 전환 시 세금 비교와 퇴직금 플랜" | "결산 결과와 대표님 말씀 기준 맞춤 방향" |

### 결과물과 성공 기준

| | A. 니즈 환기형 | B. 니즈 파악형 |
|---|---|---|
| 성공 기준 | 대표가 그 니즈를 인정 + PC 약속 | 니즈 근거 **3개 이상** 기록 + PC 약속 |
| AP 뒤 | 바로 PC 준비 탭으로 | **AP 후 기록지** 작성 → 답에 따라 후보 컨셉 점수 → PC 컨셉 결정 → PC 준비 |

## 5. 설계 추가 ②: F.F 놓치지 않기 (이미 아는 것 / 모르는 것)

기장거래처 AP에서 자주 생기는 문제: 가족관계, 사업 계획, 자녀 승계, 생활비 같은 질문을 **놓치고 돌아옵니다.** 그런데 기장거래처라 이미 아는 것도 있어서, 모든 질문을 다 할 필요는 없습니다. 그래서 **AP 전에 "내가 이미 아는 정도"를 먼저 체크**하고, 스크립트는 **모르는 것만 묻도록** 만듭니다.

### ① AP 전: F.F 체크판

항목마다 세 가지 중 하나를 고릅니다.

| 상태 | 뜻 | 스크립트에 반영되는 방식 |
|---|---|---|
| ● 확실히 앎 | 최근에 직접 들었거나 장부로 확실 | 질문하지 않음. 07·09단계 **재료로 사용** ("작년에 말씀하셨던 것처럼…") |
| ◐ 알지만 오래됨·애매 | 몇 년 전 이야기, 짐작 | **확인 질문**으로 ("아직 그대로시죠?", "그때 말씀하신 계획은 어떻게 됐어요?") |
| ○ 모름 | 들은 적 없음 | **꼭 물을 질문**으로 스크립트에 넣고 ★ 표시 |

### F.F 기본 항목

| 구분 | 항목 | 이렇게 묻기 (예) | 기장 자료에서 보이는 힌트 |
|---|---|---|---|
| 가족 | 배우자·자녀 수와 나이 | "자녀분들은 지금 몇 살이세요?" | 급여 받는 가족, 인적공제 |
| 가족 | 자녀가 하는 일 | "자녀분은 지금 어떤 일을 하세요?" | 가족 급여 여부 |
| 승계 | 자녀에게 같은 일을 시킬 수 있는지 | "나중에 이 일을 자녀분이 이어받으면 어떨 것 같으세요?" | |
| 부모 | 부모님 생존·건강·자산 | "부모님은 건강하세요?" | |
| 사업 | 단기 사업 계획 (확장·이전·신규) | "내년에 계획하고 계신 게 있으세요?" | 설비 투자, 차입 |
| 비전 | 언제까지 할지, 은퇴 후 모습 | "이 사업은 언제까지 하실 생각이세요?" | |
| 생활 | 월 생활비 | "은퇴 후 월 생활비는 어느 정도일까요?" | 대표 인출액 |
| 재산 | 사업장 외 부동산·금융자산 | "사업장 말고 따로 갖고 계신 게 있으세요?" | 임대소득, 금융소득 |
| 보험 | 기존 보험과 가입 스토리 | "보험은 어떻게 가입하셨어요?" | 보험료 지출 |
| 지출 | 큰 지출 계획 (유학·결혼·주택) | "몇 년 안에 목돈 들 일이 있으세요?" | |
| 법인 | 대표 퇴직금 규정·지분 구조 | "퇴직금 규정은 만들어 두셨어요?" | 정관, 주주명부 |

- 항목은 **컨셉별로 우선순위**가 다릅니다. A형이면 그 컨셉 AP 카드의 "꼭 받을 F.F"가 맨 위에 오고, B형이면 후보 컨셉을 가려내는 항목이 위로 갑니다.

### ② AP 중: 질문을 한곳에 몰지 않고 흩어 배치

14단계에 다 몰면 취조처럼 들립니다. 모르는 항목(○)을 자연스러운 자리에 나눠 넣습니다.

| 단계 | 들어갈 F.F |
|---|---|
| 05 시간확보 | "가족 이야기도 여쭤볼 수 있어요" 예고 |
| 08 니즈환기 | 비전, 은퇴 시점, 월 생활비 |
| 14 F.F | 가족·자녀 일·승계 의향, 재산, 보험, 지출 계획 |
| 15 다음 약속 | 다음에 가져올 자료 (재무제표, 보험증권 등) |

### ③ AP 후: 기록하고 쌓기

## 3-3. Claude가 되물은 질문과 답

| Claude의 질문 | 답 |
|---|---|
| 이전 대화 내용이 없는데 무엇을 기억할까요? | "4&7NEXT 폴더에 대화 내용을 넣어놨어" → 카톡 파일 |
| 세무사님이 맞나요? | "응 맞아 난 세무사야" |
| 허브 비밀번호를 직접 넣어 줄 수 있나요? (Claude는 비밀번호 입력 불가) | 크롬에서 직접 열고 크롬 확장 연결까지 완료 |
| 빈 문서 중 무엇부터 할까요? | "AP스크립트를 어떻게 개선할지 모르겠다, 기획해 줘" |
| 법인전환 카드를 A형·B형 둘 다로 만들까요? | "좋아" (기획서 추가 + 새 아이디어 F.F 제시) |
| F.F 12개 항목 중 빠진 게 있나요? | 공직 계획 빼기 |
| 이름을 무엇으로 할까요? | "컨셉별 AP 카드" |
| 스크립트로 뽑아 주는 건 따로 있나? | Claude 답: 허브 도구 "AP 15단계 스크립트" 탭이 스크립트를 만들고, 카드는 그 재료. 연결 전에는 Claude가 실제 거래처 정보(익명)로 직접 뽑아 줄 수 있음 → 아직 답 없음 |

## 3-4. 나만의 방식 (대화에서 말한 것만)

- **AP는 제안이 아니라 PC로 넘기는 단계**다. 실제 제안은 PC에서 한다
- 세무사들은 PC에서 제안할 것(예: 법인전환)을 정해 들고 AP에 들어가는 경우가 있다 → 그때 AP의 미션은 **그 컨셉의 니즈 환기**
- **가결산 미팅을 AP로 삼을 때**는 상대가 무엇이 필요한지 모르므로, 상대의 생각과 니즈를 **파악할 의무**가 있다 → 그걸 토대로 다음 미팅에서 PC로 제안
- 법인인지 개인인지에 따라 AP 내용이 달라진다
- 기장거래처 AP의 F.F에서 꼭 챙길 것: 가족관계, 사업계획, 앞으로의 비전, 자녀에게 같은 일을 시킬 수 있는지, 자녀가 하는 일, 월 생활비
- 실제 AP·PC 순서, 본인 질문, 본인 사례: **이 대화에서 말한 적 없음** (카드의 ★ 후킹 포인트 칸이 비어 있음)
