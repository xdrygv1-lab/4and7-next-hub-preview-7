## 숙제 1. 내 분야 아이디어: 글로 정리

### 1-1. 내 파트가 하는 일 (한 줄)

> **AP 전에 "이 회사에 무슨 말을 할 수 있는지"를 찾아 주는 내부용 기업분석 보고서.**
> 사용자는 회계사·세무사·변리사·변호사·감평사·설계사이고, 가장 큰 수혜자는 **신입 FP**입니다. 재무 지식이 없다고 가정합니다.
> 이 보고서가 계약을 직접 만들지는 않습니다. AP 15단계에서 쓸 **"말할 거리"**를 주는 근거자료입니다.
> 성공 = **다음 약속을 잡고, 대표의 Needs를 파악하는 것**.

### 1-2. 크레탑 vs 우리 보고서: 무엇이 다른가

크레탑(KODATA) 같은 기존 기업정보 보고서는 **사실을 나열**하고, 우리 보고서는 **해석해서 말로 바꿔** 줍니다.

| 구분 | 크레탑 (21쪽) | 우리 보고서 |
|---|---|---|
| 기업 개요·신용 | ✅ 상세 | 크레탑 내용을 가져다 씀 · 요약 1줄 |
| 주주현황 | ✅ 표만 제공 | **해석**: 가업상속공제 요건, 동업 리스크, 차명 의심 여부 |
| 재무제표 3년 | ✅ 숫자만 제공 | **해석**: 이익 증감 원인, 잉여금 갇힘, "누구 돈인지 모르는" 자산 |
| 종업원·급여 | ✅ 국민연금 기준 | **연결**: 인건비 → 사근복, 연구소 → 직무발명 (다른 자격사에게 넘김) |
| 주식가치 | ❌ 없음 | ✅ 상증법 방식 + 5년 후 추정 |
| 상속세 | ❌ 없음 | ✅ 추정 + 부족 재원 |
| 승계 경로 | ❌ 없음 | ✅ 이 회사에 되는 경로와 안 되는 경로 |
| 제안 컨셉 | ❌ 없음 | ✅ 신호 → 컨셉 사전 연결 + 우선순위 |
| AP 화법 | ❌ 없음 | ✅ AP 흐름별 질문 + 알아낼 것 |
| 분량 | 21쪽 (빈 섹션 다수) | **결론 1장 + 상세 몇 장** |

**→ 핵심 아이디어: 크레탑·DART·위하고 자료를 "입력"으로 받고, 우리는 "해석과 말할 거리"를 만든다.**

### 1-3. 보고서 구성 (A사 사례로 검증한 순서)

1. **한눈에 보는 결론:** 가망도(상·중·하), 핵심 이슈 3개, 우선 컨셉, 이번 AP의 목표
2. **회사 이야기:** 연혁, 대표 경력, 주요 고객, 인력 추이. 마지막에 릴렉스 멘트 예시를 붙입니다.
3. **재무 요약:** 3년 추이, 이익이 늘거나 줄어든 원인(비용 항목별), 질문 소재
4. **주식가치 평가:** 상증법 보충적 평가, 5년 후 추정, 지분 이동 타이밍
5. **상속세 추정:** 확인된 재산과 확인할 재산, 부족 재원
6. **승계 경로 & 컨셉:** 되는 경로와 안 되는 경로, 컨셉 우선순위와 담당 자격사
7. **AP 말할 거리:** 흐름별 질문과 알아낼 것
8. **다음에 받을 자료:** 다음 약속의 명분

### 1-4. 자동 판단 규칙 (신호 → 진단 → 컨셉)

허브에 넣을 "if → then" 규칙입니다. 숫자 기준은 초안이라 사례를 더 넣어 보며 조정합니다.

| 신호: 자료에서 자동 감지 | 진단 | 연결 컨셉 |
|---|---|---|
| 대표 + 특수관계인 지분 < 40% | 가업상속공제 요건 미달 가능성 ** (확인 필요)** | 일반 증여 / 가족법인 / 승계 대신 엑시트 |
| 타인 주주 2명 이상, 지분 비슷함 | 동업 구조, 유고·이탈 리스크 | 주주 간 계약 + 지분 매입 재원 (경정기) |
| 이익잉여금 > 자본금 × 50배, 또는 > 10억 | 잉여금이 법인에 갇힘 | 임원 퇴직금 규정, 배당 정책, 이익소각 |
| 배당 / 순이익 < 20% | 인출 구조 미비 | 위와 같음 |
| 장기대여금·가지급금·미수금 > 자본의 5% | 상대방 확인 필요 | 가지급금 해소, 인정이자 |
| 당기 순이익이 전기보다 30% 이상 감소 | 주식가치 하락 구간 | **지분 이동(증여) 적기** |
| 3년 연속 순이익 증가 | 주식가치 상승 구간 | "지금이 가장 쌉니다" (빠른 승계) |
| 현금성 자산 > 총자산 50% | 여유자금 많음 | 금융빌딩, 경정기 재원 |
| 대표 나이 ≥ 55 | 은퇴·승계가 다가옴 | 퇴직금, 승계 |
| 기업부설연구소 있음, 특허 0건 | 밸류업 여지 | 직무발명, 특허, 벤처인증 (변리사) |
| 인건비 / 매출 > 40%, 1인당 급여 높음 | 인건비 부담 | 사근복, 비과세 급여 (노무사) |
| 법인세 ≈ 0 (이익은 있음) | 세액공제 활용 중 | 세무대리인 칭찬 / 공제 사후관리 확인 |

### 1-5. 주식가치 계산: 허브 방식 교체 제안

- **지금:** 순자산 × 80% (경험치) → A사 기준 **20.9억**
- **제안:** 상증법 보충적 평가 → A사 기준 **31.2억** (10억 이상 차이)

| 구분 | 계산 |
|---|---|
| 순손익가치 | 3년 가중평균 순이익(최근 3 : 2 : 1) ÷ 10% |
| 순자산가치 | 자본총계 (부동산 시가 차액은 선택 입력) |
| 가중평균 | 3 : 2. 부동산 비중이 50% 이상이면 2 : 3 ** (확인 필요)** |
| 하한 | 순자산가치의 80% ** (확인 필요)** |
| 최대주주 할증 | 20%, 중소기업 제외 ** (확인 필요)** |

- 추가로 받을 입력값: **발행주식수, 대표 지분율**. 크레탑의 주주현황에서 자동으로 읽게 합니다.
- 5년 후 추정: 순이익 가정(최근 평균 또는 업종 성장률)과 배당 가정을 적용합니다.

### 1-6. 상속세 → 부족 재원 → 제안 금액 (10/14 결정 사항)

```
상속재산 = 비상장주식(1-5) + 부동산 + 금융자산 − 채무
과세표준 = 상속재산 − 일괄공제(5억) − 배우자공제(5억~30억) − 금융재산공제 (확인 필요)
상속세 = 누진세율 10%~50% (확인 필요)
부족분 = 상속세 − 대표 개인 현금성 자산 → 이게 제안 금액의 "명분"
```

- **주의:** 회사 현금은 대표 개인 현금과 다릅니다. 회사에 현금이 많아도 개인 부족분은 생길 수 있습니다. 그래서 잉여금 인출 구조와 같이 보여줘야 합니다.
- 기업 자료만으로는 개인 재산을 알 수 없습니다. 보고서에는 "확인할 재산" 목록을 띄우고, AP 질문으로 연결합니다.

### 1-7. 승계 경로 비교 (한 장)

| 경로 | 핵심 요건 | 장점 | 주의 |
|---|---|---|---|
| 가업상속공제 | 지분 40% 이상, 10년 이상 경영 등. 최대 600억 ** (확인 필요)** | 공제 규모가 큼 | 사후관리 부담. **지분 요건에서 막히는 회사가 많음** |
| 가업승계 증여세 과세특례 | 60세 이상 부모 → 18세 이상 자녀. 10억 공제 후 10%·20% ** (확인 필요)** | 미리 이전하면 이후 가치 상승분은 자녀 몫 | 상속 시 합산, 가업 요건 유지 |
| 일반 증여 (분산) | 10년 합산 | 단순함 | **주식가치가 낮을 때** 해야 효과 |
| 가족법인 활용 | 특정법인 증여의제(45조의5) 관리 | 성장 이익이 자녀 법인으로 감 | 초과배당(41조의2) 검토 |
| 이익소각·상속감자 | 자기주식 취득 절차 준수 | 잉여금 회수 + 지분 정리 | 의제배당, 부당행위 리스크 |
| 지분 매각 · 엑시트 | 매수자 | 승계자가 없을 때 대안 | 양도세, 영업권 평가 |

### 1-8. AP 공통 질문 (상품 얘기 없이)

- "주주분들은 같이 창업하신 멤버들이세요?" → 지분 구조, 차명 여부
- "주주 한 분께 일이 생기면 그 지분은 어떻게 하기로 하셨어요?" → 주주 간 계약
- "회사에 쌓인 이익을 대표님 개인으로 가져오는 계획이 있으세요?" → 인출 구조
- "회사 가치를 평가해 보신 적 있으세요?" → 주식가치, 다음 약속의 명분
- "나중에 회사는 자녀분이 맡으시나요?" → 승계 의향
- "자녀분께 증여하신 적 있으세요?" → 10년 합산 여부

## 허브 반영 요청 (우선순위 순)

1. **주식가치 계산을 상증법 보충적 평가로 교체**합니다. 입력값에 발행주식수와 대표 지분율을 추가해야 합니다.
2. **크레탑 PDF 업로드 → 자동 입력:** 주주현황, 대표 생년·경력, 종업원, 인증, 배당 이력. 크레탑 PDF는 이미지라서 AI가 그림을 읽는 방식이 필요합니다.
3. **1-4의 판단 규칙 12개를 진단에 추가:** 특히 지분 40% 미만, 동업 구조, 이익 급감에 따른 이동 적기
4. **보고서 맨 앞에 "한눈에 보는 결론" 1장:** 가망도, 핵심 이슈 3개, 우선 컨셉, AP 목표
5. **상속세 추정 → 부족 재원 → 제안 금액 연결**
6. **AP 말할 거리 섹션:** 흐름별 질문과 "알아낼 것"
7. (2단계) **AP 후 결과 입력:** 약속 여부, 파악한 Needs, 반응한 컨셉, 받은 자료
