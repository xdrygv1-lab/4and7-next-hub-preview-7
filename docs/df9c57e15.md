### 4. 나만의 방식 (AP·PC 순서, 질문, 사례)

> 작성 변리사가 직접 말한 AP·PC 순서는 **볼 수 없음.** 아래는 작성 변리사 작성 자료에서 드러나는 순서입니다. AP 15단계 변리사판은 Claude가 쓴 초안이므로 4장 4-4에 따로 두었습니다.

**A. 고객 설명 순서 (1번 PPT, 2·3번 제안서에서 드러남)**
1. 특허의 효력: 독점·배타권 → 회사의 정량 지표(정책자금, R&D, 절세)
2. 직무발명이란: 비제조 아이디어(유통 방식 자동화)도 해당한다는 예로 대상을 넓힘
3. 효과: 직원 비과세 700만 + 회사 세액공제 25%. 대표는 비과세가 안 된다는 점을 먼저 밝힘
4. "마구잡이로 주면 인정 안 된다" → 규정·절차·특허 출원이 필요한 이유
5. 특허 → 벤처인증 → 공신력
6. 3단 그림: 제도 없음(잉여금 누적) → 보상금(법인세 일부 절감) → 보상금 + 금융상품(잉여금 해소 + 리스크 헷지 + 법인세 절감)
7. 금융상품: 주식가치 조정은 월납이 커서 부담 → 재원 마련형 종신을 먼저

**B. 실행 순서 (25·28번 실행철에서 드러남)**
사실관계 확인 → 기존 서류 정리(철회, 미채택 확인) → 규정 재제정 통지 → 설명회·과반수 협의 → 위원회 구성(대표 제외) → 정관·주총 한도 → 신고·평가·승계·양도·출원 → 결산 후 산정·심의·통지·이사회·지급 → 매년 반복.

**C. 고객에게 던지는 확인 질문 〔25번 회신 요청 7가지 + 5번 요청 자료〕**

- 설계·시험에 참여한 직원이 있나? 이름은?
- 대표님 학력·설계 경력 자료가 있나?
- 이미 출원한 건과 아직인 건은? 우선심사를 원하나?
- 연구전담부서를 만들 생각이 있나?
- 품목별 원가명세, 세트·거래처별 납품 구성표가 있나?
